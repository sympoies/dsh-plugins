## 2026-09-20 - Telegram session picker stopped blocking updates

### Result

- Prepared `@sympoies/dsh-telegram` 0.6.2 so `/sessions` leaves the sequential
  Telegram poll loop free to receive the button callback that resumes an older
  conversation.

### Why / context

- The picker previously awaited its own future callback while handling the
  command update. Since Telegram updates are acknowledged and dispatched in
  order, the callback could never reach the waiting picker and the bot stopped
  receiving all later messages.

### Evidence

- A focused router regression reproduces the blocked handler independently of
  Telegram and passes together with the existing session-history tests.

## 2026-09-19 - Independent package release pipeline converged

### Result

  package-owned compatibility inputs, build one tarball, and publish the same
